# 0004：搬送経路の退役と議題データの保全

状態：採用。2026-11-02の本人指示による候補実装。正式反映は対象のプルリクエストと検証結果で確認する。

## 決定と理由

`CMUX`搬送を廃止し、既存アプリ席へのローカル通信と手動貼付を残す。
旧経路を互換運用として残す案は、利用者が廃止した経路への誤送信を許すため採らない。
過去の議事録・送達記録は削除せず、送信処理だけを停止する。

## 不変条件と検知

- 公開コマンドで退役経路を選べない。直接呼出しも送信前に拒否する。
- 旧受領記録の再利用では外部処理を呼ばず、記録を変更しない。
- 同じ議題名を再作成しても、議事録と実行状態を上書きしない。
- 通常の運用データはソースの作業場所と別の明示した`Git ROOT`へ保存する。

検知は既存のコマンド引数検査、送信経路の試験、議題再作成の回帰試験、外部保存先のスモークで行う。

## 修復と証拠

退役経路を指定する呼出元は既存アプリ席へ移行する。送達不明の依頼は再送せず、同じ依頼の状態を照合する。
既存の追跡済み議事録は履歴資料として保持し、保全と内容照合なしで移動・削除しない。
変更対象の差分、試験結果、固定した配布物と保存先の検証を、対象のプルリクエストへ紐付ける。
共通の出力検査や権限設定は本リポジトリで変更しない。
